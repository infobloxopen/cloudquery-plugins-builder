# Data Model: OCI Image Pipeline for CloudQuery Plugins

**Feature**: 001-oci-image-pipeline
**Date**: 2026-02-12

## Entities

### 1. Plugin Manifest (`plugins.yaml`)

The top-level configuration file that drives all builds.

```yaml
# JSON Schema: schemas/plugins-manifest.schema.json
apiVersion: v1                              # Manifest schema version
plugins:
  - name: postgresql                        # Plugin short name (lowercase, alphanumeric + hyphens)
    kind: destination                       # "source" or "destination"
    version: v8.14.1                        # Semantic version with v prefix
    upstream:
      repo: https://github.com/cloudquery/cloudquery
      tag: plugins-destination-postgresql-v8.14.1
      commit: <sha>                         # Full 40-char commit SHA that the tag resolves to
    build:
      plugin_dir: plugins/destination/postgresql  # Path within the monorepo
      go_version: "1.25.6"                        # Pinned Go version for this build
      bin_name: plugin                             # Output binary name (default: "plugin")
      ldflags_version_path: >-                     # Go ldflags path for version embedding
        github.com/cloudquery/cloudquery/plugins/destination/postgresql/v8/resources/plugin.Version
```

**Fields**:

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `apiVersion` | string | ✅ | Schema version (currently `v1`) |
| `plugins` | array | ✅ | List of plugin entries |
| `plugins[].name` | string | ✅ | Plugin short name (used in image name) |
| `plugins[].kind` | enum | ✅ | `source` or `destination` |
| `plugins[].version` | string | ✅ | Semantic version with `v` prefix |
| `plugins[].upstream.repo` | string (URL) | ✅ | Upstream git repository URL |
| `plugins[].upstream.tag` | string | ✅ | Exact git tag to check out |
| `plugins[].upstream.commit` | string (SHA) | ✅ | Commit SHA the tag resolves to |
| `plugins[].build.plugin_dir` | string | ✅ | Relative path to plugin source within repo |
| `plugins[].build.go_version` | string | ✅ | Go toolchain version to use |
| `plugins[].build.bin_name` | string | ❌ | Output binary name (default: `plugin`) |
| `plugins[].build.ldflags_version_path` | string | ❌ | Go package path for `-X` version injection |

**Validation rules**:
- `name` must match `^[a-z][a-z0-9-]*$`
- `version` must match `^v\d+\.\d+\.\d+(-[a-zA-Z0-9.]+)?$`
- `upstream.commit` must be a 40-character hex string
- `upstream.tag` must be non-empty
- `upstream.repo` must be a valid HTTPS URL
- `build.plugin_dir` must not contain `..` or start with `/`
- `build.go_version` must match `^\d+\.\d+(\.\d+)?$`
- Combination of `(name, version)` must be unique across all entries

**State transitions**: N/A (static configuration file)

### 2. OCI Image

The published container image in GHCR.

**Image reference pattern**: `ghcr.io/<org>/cloudquery-plugin-<name>:<version>`

**OCI Labels** (set at build time):

| Label | Source | Example |
|-------|--------|---------|
| `org.opencontainers.image.source` | This repo's URL | `https://github.com/infobloxopen/cloudquery-plugins-builder` |
| `org.opencontainers.image.revision` | This repo's commit SHA | `abc123def456...` |
| `org.opencontainers.image.created` | Build timestamp (RFC-3339) | `2026-02-12T10:30:00Z` |
| `org.opencontainers.image.title` | Plugin display name | `cloudquery-plugin-postgresql` |
| `org.opencontainers.image.description` | Plugin description | `CloudQuery postgresql destination plugin` |
| `org.opencontainers.image.licenses` | License identifier | `MPL-2.0` |
| `io.cloudquery.plugin.upstream-repo` | Upstream repo URL | `https://github.com/cloudquery/cloudquery` |
| `io.cloudquery.plugin.upstream-tag` | Upstream git tag | `plugins-destination-postgresql-v8.14.1` |
| `io.cloudquery.plugin.upstream-commit` | Upstream commit SHA | `fedcba987654...` |
| `io.cloudquery.plugin.kind` | Plugin kind | `destination` |
| `io.cloudquery.plugin.name` | Plugin name | `postgresql` |
| `io.cloudquery.plugin.version` | Plugin version | `v8.14.1` |

**Attached OCI artifacts**:
- SBOM (SPDX format, generated by Buildx/syft)
- SLSA provenance attestation (generated by Buildx)
- Cosign signature (keyless via GitHub OIDC)

### 3. Build Index Record

A provenance record linking a manifest entry to its published image.

**Schema** (`build-index.json`):

```json
{
  "$schema": "schemas/build-index.schema.json",
  "generated_at": "2026-02-12T10:35:00Z",
  "ci_run_url": "https://github.com/<org>/<repo>/actions/runs/123456",
  "images": [
    {
      "plugin_kind": "destination",
      "plugin_name": "postgresql",
      "version": "v8.14.1",
      "image": "ghcr.io/<org>/cloudquery-plugin-postgresql:v8.14.1",
      "digests": {
        "index": "sha256:aabbcc...",
        "linux/amd64": "sha256:ddeeff...",
        "linux/arm64": "sha256:112233..."
      },
      "upstream_repo": "https://github.com/cloudquery/cloudquery",
      "upstream_tag": "plugins-destination-postgresql-v8.14.1",
      "upstream_commit": "fedcba987654...",
      "build_timestamp": "2026-02-12T10:30:00Z",
      "sbom_attached": true,
      "provenance_attached": true,
      "cosign_signed": true
    }
  ]
}
```

**Fields**:

| Field | Type | Description |
|-------|------|-------------|
| `generated_at` | string (RFC-3339) | When the index was generated |
| `ci_run_url` | string (URL) | GitHub Actions run URL |
| `images[]` | array | One entry per built image |
| `images[].plugin_kind` | string | `source` or `destination` |
| `images[].plugin_name` | string | Plugin short name |
| `images[].version` | string | Plugin version |
| `images[].image` | string | Full image reference with tag |
| `images[].digests` | object | Manifest digest (index) + per-arch digests |
| `images[].upstream_repo` | string | Upstream repository URL |
| `images[].upstream_tag` | string | Upstream git tag |
| `images[].upstream_commit` | string | Upstream commit SHA |
| `images[].build_timestamp` | string | Image build timestamp |
| `images[].sbom_attached` | boolean | Whether SBOM was attached |
| `images[].provenance_attached` | boolean | Whether provenance was attached |
| `images[].cosign_signed` | boolean | Whether image was signed |

### 4. Kubernetes Example Set

Per-plugin deployment templates. Not a data model entity per se, but a structured output.

**Components per plugin**:
- `Deployment` — runs the plugin gRPC server
- `Service` — exposes the gRPC port (ClusterIP)
- `Job` or `CronJob` — CloudQuery sync job referencing the plugin service

**Naming convention**:
- Deployment: `cloudquery-plugin-<name>`
- Service: `cloudquery-plugin-<name>`
- Job: `cloudquery-sync-<name>`
